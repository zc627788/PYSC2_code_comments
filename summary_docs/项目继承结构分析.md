# LLM-PySC2 项目继承结构分析

## 🏗️ 主要继承层次

### 1. 配置系统继承链
```
AgentConfig (基础配置)
├── TerranAgentConfig (人族配置)
├── ProtossAgentConfig (神族配置)
└── ZergAgentConfig (虫族配置)

ProtossAgentConfig
└── Protoss (config_combat.py)
```

### 2. 智能体系统继承链
```
MainAgent (主智能体)
└── MainAgentTSSPysc2 (experiment_llm_36strat.py)

LLMAgent (LLM智能体)
├── CombatGroup1 (战斗组1)
├── CombatGroup6 (战斗组6)
├── Commander (指挥官)
├── Builder (建造者)
└── Defender (防御者)
```

### 3. 核心模块继承链
```
BaseTranslatorO (观察转换基类)
├── CombatGroupTranslatorO (战斗组观察转换)
├── CommanderTranslatorO (指挥官观察转换)
└── DeveloperTranslatorO (开发者观察转换)

BaseTranslatorA (动作转换基类)
└── DefaultTranslatorA (默认动作转换)

BaseCommunicator (通信基类)
└── DefaultCommunicator (默认通信器)
```

## 🎯 学习建议

### 从简单到复杂的学习路径：
1. **先看基础类** (AgentConfig)
2. **再看具体实现** (ProtossAgentConfig)
3. **最后看应用** (MainAgentTSSPysc2)
